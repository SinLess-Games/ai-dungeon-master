# Please report suspected security vulnerabilities responsibly.
# Do not publicly disclose vulnerabilities before they have been
# investigated and, where appropriate, remediated.
#
# Include enough information to reproduce the issue, including:
# - A description of the vulnerability
# - Affected URL, endpoint, or component
# - Steps to reproduce
# - Expected versus actual behavior
# - Proof-of-concept details where appropriate
# - Potential impact
#
# Please avoid:
# - Accessing or modifying data belonging to other users
# - Destructive testing
# - Denial-of-service testing
# - Social engineering
# - Automated high-volume scanning
# - Persistence after demonstrating the vulnerability
