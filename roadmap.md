# Roadmap — D&D 3.5 AI Dungeon Master

## Phase 1 — Playable solo core

- [ ] Auth (email + Google), roles, schema, offline-first cloud sync of characters/campaigns/worlds/maps
- [ ] Design system (dark arcane theme, fonts)
- [ ] Rules data: races, base classes, skills, feats, alignments
- [ ] Rules engine: derived stats, encumbrance (toggleable)
- [ ] Dice roller with large-roll support (100d6+)
- [ ] Local save layer (swap to Cloud when available)
- [ ] Dashboard
- [ ] Character creator with inline explanations
- [ ] Character sheet (live, editable)
- [ ] Campaign setup wizard (style, type, length, pace, DM temperament, world notes, house rules)
- [ ] Streaming AI DM with state tools, player rolls, grants, alignment tracking
- [ ] Standalone world builder + world map

## Phase 2 — Reference, loot, export

- [ ] Rules wiki with search + filters
- [ ] Loot tracking (on-person / stored / party) — editable pools, split/assign, item history
- [ ] PDF character sheet export
- [ ] Party + NPC companions (roster, outfitting, DM-run or player-run)

## Phase 3 — Maps & atmosphere

- [ ] World map with travel + exploration
- [ ] Isometric 2.5D tactical map: elevation, multi-level, props, traps, fog, tokens
- [ ] Traps, hazards, location builder
- [ ] Bestiary + encounter builder
- [ ] Sound and music
- [ ] House rules engine

## Phase 4 — Multiplayer & monetization

- [ ] Invites, membership, realtime sessions
- [ ] Subscription paywall for multiplayer (Stripe checkout, subscriptions table, webhook, billing portal, admin subscriptions view)
- [ ] Gift codes + admin console

## Phase 5 — Advanced systems

- [ ] Prestige classes + psionics
- [ ] Epic levels 21+ and expanded sourcebooks
- [ ] Crafting, alchemy, enchanting, rituals
- [ ] Leadership, cohorts, followers
- [ ] Factions, armies, mass combat, strongholds
