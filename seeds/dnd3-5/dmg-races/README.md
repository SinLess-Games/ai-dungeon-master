# Dungeon Master's Guide races

This seed pack materializes the two playable race examples from the user's by-book Dungeon Master's Guide list.

- **Gold Dwarf** — DMG example subrace. It inherits standard dwarf traits, uses +2 Constitution / -2 Dexterity, and replaces the dwarf attack bonus against orcs and goblinoids with +1 against aberrations.
- **Half-Human Elf** — DMG example modified race. It inherits half-elf traits, loses the half-elf Diplomacy and Gather Information racial bonuses, gains elven martial weapon proficiencies, and uses Wizard as favored class.

The seed files include their source identity, creator-facing traits, subtypes, and inherited language access. These are level-adjustment +0 player options and are enabled for character creation.
